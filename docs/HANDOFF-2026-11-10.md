## 2. Fixed

1. **Six TypeScript errors in Vercel's function build** (`adbcc55`). Vercel compiles `api/` without `strict`, where zod types turn every field optional and `result.ok` stops narrowing. The project's own strict typecheck never saw it.
   - Service input types now come from the zod schemas: `AssistantChunkInput`, `RecordingReportInput` (`shared/api/interviews.ts`), `CandidateListFilters` (`shared/api/candidates.ts`).
   - `createUploadTicket` takes `CreateUploadInput` (it never read `contentType`).
   - `email.service.ts` checks `result.ok === true`.
   - To reproduce: `npx tsc --noEmit --target ES2022 --module NodeNext --moduleResolution NodeNext --skipLibCheck --esModuleInterop --types node --strict false api/index.ts`.
2. **`ERR_HTTP_HEADERS_SENT` crash in the error handler** (`server/middleware/errors.ts`). It tried to answer a response that was already sent and hid the real error. It now logs one warning line and returns.
3. **Pages stuck on skeletons for 25 s** (`cfa67cb`, `server/app.ts`). A request waiting on a dead pooler connection used to fail only at 25 s.
   - A **GET or HEAD** that has not answered after **8 s** is run once more on a fresh connection pool, and only fails after another **12 s** (503).
   - Writes keep 25 s and the AI routes 57 s. A write is never run twice.
   - `createApp(options)` now takes `readRetryAfterMs` and `readRetryLimitMs` so tests can shorten the timers.
4. **Admins page hang** (`c87726b`, `server/modules/admin/accounts.service.ts`). `adminsOverview` fired five queries at once, which opened five new pooler connections in the same instant. They now run one at a time, and each step logs `[admins] "<step>" took Nms` or `is still waiting after 4s`.
5. **Fluid compute on** (`63e0c1f`, `vercel.json` `"fluid": true`). One page load fired 4–5 requests, each booting its own cold function instance.
6. **Login 401s after the database move**: the new database starts empty. Data was copied from the old project (see section 4).
7. **Assistant "n8n HTTP 403"**: the shared secret in Vercel did not match n8n's Header Auth value (see section 4, the n8n table).
8. **Assistant "n8n HTTP 500"**: two bugs in the workflow, both fixed in n8n.
   - The `lookup` and `propose` tools declared their input as one `$fromAI('arguments', …)` blob, which n8n rejects (`Invalid parameter key`). Each tool now has named inputs.
   - `gemini-3-flash-preview` returned `400 Thought signature is not valid` after a tool call. The agent now uses `models/gemini-2.5-flash`.
9. **Voice transcription "not supported via Gateway credits"**: Gemini audio transcription is not on the gateway. The notes and assistant workflows now use the OpenAI transcribe node (gateway-supported).
10. **Escape closed the whole chat** along with the window opened from it (`AssistantDock.tsx`). It now ignores Escape while any `aria-modal` dialog is open, which also fixes the existing preview windows.
